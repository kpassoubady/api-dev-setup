# Fundamentals of API Development - Setup Instructions

Welcome! This repository contains the installation guides and a verification quick start project for the **Fundamentals of API Development** course.

- Start with [install/install.md](install/install.md) for the installation instructions (macOS and Windows).
- Then use [quickstart-project](quickstart-project/) to verify your installation — a small Spring Boot REST API you'll open in IntelliJ, run with Maven, call from Postman, and test with JUnit5.
- See [catalog/api-dev-am-pm-outline.md](catalog/api-dev-am-pm-outline.md) for the full course outline.
